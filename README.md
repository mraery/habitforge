## 🌟 Öne Çıkan Özellikler

- **🟩 GitHub Tarzı Yıllık Isı Haritası (Heatmap Matrix):**
  - Alışkanlıklarınızı yıl boyunca gün gün yeşil kareler matrisiyle görselleştirin.
  - İster tüm alışkanlıklarınızın ortalama devamlılığını, isterseniz seçtiğiniz tek bir alışkanlığın disiplinini görün.
- **⚡ Günlük Hızlı Kontrol Listesi:**
  - Kitap okuma, kod yazma, 2.5L su içme, egzersiz ve farkındalık gibi alışkanlıkları tek dokunuşla tamamlayın.
  - Günlük tamamlama yüzdesi ve motive edici zihniyet alıntıları.
- **🔥 Seri (Streak) Takipçisi:**
  - Mevcut aktif seriniz ve ulaştığınız tüm zamanların en iyi serisi (Best Streak).
- **🏆 Başarı Rozetleri & Kilometre Taşları:**
  - *İlk Kıvılcım* (1 Gün), *3 Günlük Ateş*, *Haftalık Fatih* (7 Gün), *21 Gün Alışkanlık Kuralı*, *Çelik İrade* (50 Gün) ve *100 Günlük Asırlık Efsane* rozetleri.
- **🔒 %100 Çevrimdışı ve Güvenli:**
  - İnternet gerektirmez, verileriniz hiçbir sunucuya gitmez, yerel cihazınızda saklanır.

## 📱 İndirme & Kurulum

Android için derlenmiş hazır APK dosyasını doğrudan [Releases](https://github.com/mraery/habitforge/releases) sayfasından indirebilirsiniz.

```bash
# Projeyi klonlayın
git clone https://github.com/mraery/habitforge.git

# Paketleri yükleyin
flutter pub get

# Uygulamayı çalıştırın
flutter run
```
